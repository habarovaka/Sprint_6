Автотесты для сервиса «Яндекс.Самокат»
Проект содержит автоматизированные UI-тесты для проверки функциональности заказа самоката и работы разделов FAQ (часто задаваемые вопросы).

Стек технологий
* Python 3
* Selenium WebDriver
* PyTest
* Паттерн Page Object Model (POM)

Подготовка и запуск

Установите зависимости:
pip install -r requirements.txt
